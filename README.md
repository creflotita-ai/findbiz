# FindBiz MVP — Step 1

This is a front-end prototype for the FindBiz concept.

Included:
- Responsive landing page
- Hero section
- Features
- How it works
- Search interface
- Sample lead results
- Pricing section

IMPORTANT:
The search currently uses sample data. It does NOT yet connect to live business data.
That is intentional: the next stage is to choose a legitimate data/API source and build the backend.

To run locally:
1. Open index.html in a browser.
2. For a better local server, use any simple static server.

Suggested next build:
1. Choose/verify brand and domain.
2. Connect a backend/database.
3. Connect a legitimate business-data provider.
4. Build website-presence verification.
5. Add authentication and billing.
6. Add AI website previews.
