# FindBiz V9 — Profit-Focused Lead Finder

This version restores the broader product-style interface while keeping the live business search connected to the existing Cloudflare Worker.

Included:
- Landing page built around customer value and conversion
- Login and sign-up UI preview
- Pricing tiers: Free, Pro, Agency
- Worldwide location search
- Live business results
- Website/no-website opportunity signals
- Phone/address/map information when available
- Clear path toward paid subscriptions

IMPORTANT:
- Login/signup and pricing buttons are UI previews only. No real authentication or payments are connected yet.
- Pricing is illustrative and should be finalized before taking payments.
- "No website listed" means no website was present in the returned OpenStreetMap data; it is not proof the business has no website.
- Search data comes through the existing Cloudflare Worker.
